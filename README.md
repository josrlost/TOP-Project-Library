# TOP-Project-Library
This is a project assignment from The Odin Project, specifically from their JavaScript module, within the
chapter "Organizing Your JavaScript code". This is the Project: Library assignment, and it consist of 
creating some sort of content display or table that records certain pieces of detail in terms of a reading list.
The objective of the assignment is to exhibit understanding of object's prototypal inheritance, how to create a
object function contructor for object instances, how to assign functions to the prototype of an object instance
for the prototypal inherance. Also, the project requires  understanding of DOM manipulation.
